# 尖山埤植物導覽

台糖柳營尖山埤渡假村的線上植物導覽網站。遊客用手機打開，就能：

- **看自己在地圖的哪裡**（GPS 定位），並列出「我附近」的植物與距離
- **點地圖上的分區**，看那一區有哪些植物
- **搜尋植物**（中文名、別名、學名皆可），看它在園區哪裡
- 依用途篩選：食用、藥用、實用、景觀、外來入侵、有毒注意
- 每種植物有簡介、用途與注意事項
- 手機版像 Google 地圖：清單是可以上下拖曳的抽屜，往下滑只看地圖、往上滑查資料
- 地圖可以兩指旋轉；點左上角指北針可讓地圖跟著手機方向轉，再點一次回到北方朝上
- `signs.html` 可列印每種植物的 QR Code 牌卡，取代需要維護的實體立牌

資料來源：國立臺南大學 生態暨環境資源學系〈生態調查－台糖柳營尖山埤渡假村〉第二組（114 年 6 月，指導教授 謝宗欣）。

## 檔案結構

```
index.html        主頁（地圖＋清單）
signs.html        QR Code 牌卡列印頁
css/style.css     樣式
js/app.js         程式（不需要任何建置工具）
data/plants.js    植物資料：名稱、學名、科名、用途、注意事項
data/geo.js       分區範圍與植物點位座標
images/plants/    （選用）植物照片
```

純靜態網站，推上 GitHub 後到 **Settings → Pages**，Source 選 `main` 分支根目錄即可上線。
網址會是 `https://bang-jj.github.io/jianshanpi/`。

## 如何修改資料

### 新增或修改植物
編輯 `data/plants.js`，複製一筆既有資料改內容即可。`id` 用英文、不可重複，網址與點位都會用到它。

### 加照片
把照片放進 `images/plants/`（建議寬 1200px 以內的 jpg），在該植物資料加上：
```js
photo: "images/plants/yuetao.jpg",
```

### 新增點位
在 `data/geo.js` 的 `POINTS` 加一行：
```js
{"id": "p60", "plant": "yuetao", "lat": 23.26101, "lng": 120.39012, "zone": "E"},
```
座標可以在 Google 地圖上長按該位置取得。

## 關於點位座標的精度

原始調查只留下 QGIS 截圖（報告圖五），沒有座標檔。截圖的底圖是 OpenStreetMap，
但**地圖畫面被旋轉了約 90°（北方朝右）**。本專案把截圖與 OpenStreetMap 的湖岸線疊合比對
（重疊率約 98%，比例尺約 0.52 公尺／像素），再把每個點換算成經緯度。

因此目前點位是「大致位置」，誤差約 10–20 公尺。若還保有當初的 QGIS 專案，
可以把點位圖層「匯出 → 另存圖徵為 GeoJSON（座標系統選 EPSG:4326）」，
再依欄位對應改寫 `POINTS`，就能得到精確位置。

截圖中芋頭旁的 1 點、龍葵與扁軸木之間的 2 點。

## 待確認的資料

- **水珠母乳**：可能是「豬母乳」（馬齒莧）或「水豬母乳」（圓葉節節菜），需現場確認。
- **秀貴甘蔗**、**金葉黃槐**：品種／品系名稱待確認。
- **百合**：種類未記錄。
- **苦菜**：調查表有列，但「苦菜」可指多種植物，未收錄於網站。

調查原始紀錄中的「黃鶴菜」「紅翅露兜樹」已更正為「黃鵪菜」「紅刺露兜樹」。
